Sizzla 3000 0.29.0 – macOS-förhandsversion och fortsatt Windows 11-stöd.

- Separata DMG- och ZIP-filer för Apple Silicon (arm64) och Intel (x64), macOS 15+.
- Mac-appen finns kvar efter att sista fönstret stängts; Dock-ikonen öppnar huvudfönstret igen. Avsluta med ⌘Q.
- WhatsApp Desktop kan öppna den anställdas chatt även på Mac. Ingen text skickas automatiskt.
- Samma företag, export/import och databasschema 10 som Windows. Flytta data via säkerhetskopiering.
- GitHub Actions kör enhets-, gränssnitts- och paketerade skrivbordstester på båda Mac-arkitekturerna innan release publiceras. Windows tester och installationsbygge finns kvar.

Målplattform macOS 15+, med automatiska tester på macOS 15. Äldre Mac-versioner är inte praktiskt verifierade. Mac-byggena är osignerade och inte notarierade; Gatekeeper kan hindra öppning. Apple-signering behöver ordnas inför bred distribution. Windowsinstallationen är också osignerad. Detta är en förhandsversion.

Under Assets: välj .exe för Windows, eller .dmg/.zip med arm64 för Apple Silicon respektive x64 för Intel Mac. Se README för installation och datakatalog.
